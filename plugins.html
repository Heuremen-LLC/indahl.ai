CLAUDE CODE PLUGINS

Three plugins for Claude Code. Add the marketplace once, then install the ones you want.

/plugin marketplace add Heuremen-LLC/claude-plugins
/plugin install standards@heuremen
/plugin install readcheck@heuremen
/plugin install qia-calibration@heuremen

standards

/standards <arXiv id, DOI, file or claim> checks a paper or a measured claim against the Standards claim codes F1 to F7 and returns a recount card. Every code gets one of four statuses: PRESENT, ABSENT, CANNOT_TELL with its reason, or NOT_APPLICABLE. Every PRESENT carries a verbatim quote and where it sits in the paper. Any recompute shows its arithmetic from the paper’s printed numbers, with the rounding range. The card names no cause.

readcheck

A gate for research repositories. When Claude Code commits a reading (a results, outcomes or readings file), the commit is refused unless a complete check block, CHECK.json, sits beside it. The block has one answer for each of the Standards recount requirements REQ-01 to REQ-13. /readcheck new writes a blank block, /readcheck verify checks one.

qia-calibration

/qia-check runs the QIA calibration checker on IBM Quantum calibration records: before a run (stale figures, zero error values, T2 above 2 × T1, T1 and T2 measured apart) and after it (the record in force and what changed during the run). Your files are opened read-only. The same checker installs on its own with pip install qia-check. More in the QIA Calibration Pack.

Source, licenses and README: github.com/Heuremen-LLC/claude-plugins.
