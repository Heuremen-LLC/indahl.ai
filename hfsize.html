HFSIZE · Stated Size Against the Weights

Division: IRIS

Does the size in a model's name match the weights?

Many model names state a size, such as 8B or 135M. For the most downloaded models on Hugging Face this page compares that size with the parameter count Hugging Face computes from the weight files. Names with no size, with several sizes, or with a mixture-of-experts pattern, and repositories that are quantized or packed, are not comparable and are counted apart.

The plan, with its dated addendum and notes, was committed before the first model was read. The band that counts as agreement was fixed before the first read. A row outside it is opened by hand and the reason written beside it. The page does not say that the name is wrong. Most rows are a name that states one part of a model or the model a draft checkpoint pairs with.
