Does a model name keep the same weights?

A Hugging Face repository name is a pointer. Anyone who pins a model by name expects the weight files behind it to stay the same. We read the weight files of the 1,000 most downloaded models and read them again on later passes. A model that leaves the top 1,000 stays in the record, so the number of models read can be above 1,000. A model is the same when its weight files are identical on two passes, changed when a weight file was replaced, added or removed, and gone when the repository no longer resolves.

Changed is ABOVE when the lower end of the 95 percent interval of the changed share is above 1 percent, CONSISTENT when the upper end is below 1 percent. The first pass has nothing to compare with. The first table counts each model by its latest pair of passes, so a model that changed on one pass and stayed the same on the next is not in it. The table of models that changed on any pass counts each such model once, was defined after the first read and carries no outcome. Weights in subfolders and gated repositories are not read. A model can change on more than one pass, so change events can outnumber changed models. Every change is listed after it is read in full, and changes not yet read in full are counted above the tables as awaiting a read in full. Plan, addenda and code.
