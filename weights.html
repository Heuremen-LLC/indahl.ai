Does a model name keep the same weights?

A Hugging Face repository name is a pointer. Anyone who pins a model by name expects the weight files behind it to stay the same. We read the weight files of the 1,000 most downloaded models and read them again on later passes. A model that leaves the top 1,000 stays in the record, so the number of models read can be above 1,000. A model is the same when its weight files are identical on two passes, changed when a weight file was replaced, added or removed, and gone when the repository no longer resolves.
