# indahl-margin

For a sharp prediction, design or result, find how far its key parameter can move before the conclusion fails, and compare that margin with the parameter's own stated uncertainty. Returns ROBUST, FRAGILE (margin smaller than the uncertainty) or CANNOT_TELL, with the break point. Use before an expensive run, a preregistration, a launch decision, or when a result rests on one tuned number. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/margin
