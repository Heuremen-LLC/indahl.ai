# indahl-batch

Run a check or audit over something too big for one context window (a whole site, a large repo, a folder of papers) without losing the instructions: short brief, item list, batches with fresh workers, results to files, merge with nothing dropped. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/batch

## Services this plugin contacts

None. It runs inside your session.
