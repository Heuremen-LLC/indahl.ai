# indahl-clause

Check the sentences that report a result for wording that claims more than the comparison showed: an item that is wrong on its own described as if the paired comparison moved, a CONSISTENT reported as 'the same', a non-significant difference reported as 'no difference', a cause named where only an association was measured. Returns each sentence with KEEP or REWORD and the exact replacement. Use on results sections, eval write-ups, clinical and product summaries, and press releases. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/clause

## Services this plugin contacts

None. It runs inside your session; it opens only the sources you point it at.
