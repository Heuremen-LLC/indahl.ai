# indahl-outside-ruler

Check your own work against a ruler you did not build before it goes out: a referee pass on the raw material, ten checks drawn from mistakes that cost real corrections, and a STANDS / MOVES / HOLD verdict with exact changes. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/outside-ruler

## Services this plugin contacts

None. It runs inside your session.
