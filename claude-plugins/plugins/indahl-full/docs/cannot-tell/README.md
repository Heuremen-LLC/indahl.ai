# indahl-cannot-tell

Permission and a procedure for answering 'I can't tell yet' instead of forcing an answer: the range of what is possible, the facts that would decide it, and the cheapest next step. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/cannot-tell

## Services this plugin contacts

None. It runs inside your session.
