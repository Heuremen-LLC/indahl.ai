# Both

Most bad conclusions are not wrong facts; they are a second explanation dropped too early. Keeping two live readings side by side,
and saying so, is often the honest state of the work. Heuremen LLC, https://indahl.ai.

## 1. Name the two readings

Write each as a plain claim that could be true:

- **A**: ...
- **B**: ...

They should predict different things somewhere. If they predict the same thing everywhere, they are one reading with two names;
say so and stop.

Always add the other two states, so the answer is never forced into one of the first two:

- **BOTH**: each is true in part (two causes adding or multiplying, two groups behaving differently).
- **NEITHER**: something not yet named explains it.

## 2. Keep two ledgers

For each piece of evidence, one row: what it is, where it came from, and its bearing on A, on B, on BOTH and on NEITHER (supports /
against / silent). Do not let a piece of evidence count for A just because A is ahead.

Look specifically for:

- **The instrument reading**: could the pattern come from how it was measured (the tool, the sample, the filter, the timing) rather
  than from the thing measured? That is usually B, and the easiest one to drop.
- **The split**: does the effect have a part common to every case and a part that grows with the variable? Report the two parts
  separately.
- **The sign**: if several cases each "agree", check they agree in direction, not only in size.

## 3. Find the separating test

Name the observation where A and B predict different things, and what each predicts there. If it exists and is cheap, run it or say
how. If it does not exist yet, that is the finding: the question cannot currently be split.

## 4. Report the state

One of: **A**, **B**, **BOTH**, **NEITHER**, or **OPEN** (both still live; give the separating test). Show the two ledgers.
Change the state only when evidence moves it, and say which row moved it.

## Do not

- Do not pick the more elegant reading because it is elegant.
- Do not average A and B into a compromise neither side claims.
- Do not drop B quietly because a reader wants one story. If you report A, say what happened to B.
