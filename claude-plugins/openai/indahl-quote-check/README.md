# indahl-quote-check

Check every quotation in a draft, article, report or another skill's output against its source, word for word: VERBATIM, ALTERED, PARAPHRASE_IN_QUOTES, MISATTRIBUTED, NOT_FOUND or CANNOT_TELL, with the source text beside it. Use before publishing anything that quotes a person, a document or a paper. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/quote-check

## Services this plugin contacts

None. It runs inside your session; it opens only the sources you point it at.
