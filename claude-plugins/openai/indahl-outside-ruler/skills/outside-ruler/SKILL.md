# Outside ruler

The person who made the work cannot be its only check: they read what they meant, not what they wrote. Every check below is here
because skipping it cost us a correction in public. Heuremen LLC, https://indahl.ai.

## 1. Give the referee the raw material, not your summary

- The referee (a fresh subagent if the host can start one, otherwise a fresh pass with your own notes put aside) gets the original
  data, the source documents and the draft. Not your explanation of them: your map of the sources is your seat, not theirs.
- Ask it to find what is wrong, not to confirm what is right.

## 2. The checks

Each gets an answer: holds (and what was checked), fails (and where), or cannot tell.

1. **Compared like for like?** Was the comparison set up before the result was seen, with the same counting, the same time window
   and the same filters on both sides? Does the filter that decides what counts depend on the thing being counted?
2. **Did a summary hide a difference?** Count item by item (what flipped each way) before quoting an average or a net figure.
   Compare against how much the same setup varies when nothing changes.
3. **Is the stated figure the same quantity?** A vendor's "error rate" may be an average, a best case or a different definition.
   Name what each number is before comparing them.
4. **Every number from the record?** Each count, date and version read from the file, log or source, never from memory.
5. **Quotes verbatim?** A paraphrase never sits inside quotation marks.
6. **Four outcomes kept apart?** Nothing returned, refused, held and answered are not merged; CANNOT_TELL is not folded into yes or no.
7. **Defined after the fact, labelled?** Anything chosen after seeing the result says so.
8. **One source of truth?** The number on the page is the number in the ledger or data file it came from; if it lives in two places,
   both match.
9. **Checked live?** After it ships, the live page or artifact is read back, not the local copy.
10. **The cheapest rebuttal tested?** Write the one-sentence objection the other side would make, then check it against data. An
    objection that only sounds right does not cut a line; one that survives its test does.

## 3. Verdict

- **STANDS**: every check holds.
- **MOVES**: list each change exactly (line, old, new) and apply them before release.
- **HOLD**: a check fails in a way that changes the conclusion; say what would clear it.

Keep the referee's notes beside the release as its receipt. A correction found later is written beside the original, never over it.
