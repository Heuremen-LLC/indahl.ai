# indahl-number-check

Check every number in a report, memo, deck, dashboard or another skill's output against its source: each figure traced, then marked HELD, MOVED, NO_SOURCE or CANNOT_TELL with the source line beside it. Use after any research, finance, analytics or business-report skill, or before sending anything with numbers in it. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/number-check

## Services this plugin contacts

None. It runs inside your session; it opens only the sources you point it at.
