# indahl-correct

Record a correction beside the original, never over it: what was wrong, who caught it, when, the evidence, the corrected text, and whether every place that cited the original was reached. Produces a corrections ledger entry and a list of downstream places to update. Use when an error is found in anything already published or sent - a paper, a page, a report, a dataset, a message. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/correct

## Services this plugin contacts

None. It runs inside your session; it opens only the sources you point it at.
