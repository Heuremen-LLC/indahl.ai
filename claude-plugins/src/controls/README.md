# indahl-controls

Audit a study's, benchmark's or check's positive and negative controls before it runs: was each control chosen independently of the value the rule reads, can the rule fire on it at all, and is the hardest known positive reachable under the rule's own limits. Returns a control table and READY, FIX_CONTROLS or CANNOT_TELL. Use when designing an experiment, an eval, a detector or any test whose silence will be read as a result. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/controls

## Services this plugin contacts

None. It runs inside your session; it opens only the sources you point it at.
