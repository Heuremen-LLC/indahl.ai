# indahl-source-check

Check every citation, reference or link in a paper, report, answer or another skill's output: does it exist, does it say what the text claims, which version was read. Marks each SUPPORTS, PARTIAL, CONTRADICTS, SILENT, NOT_FOUND or CANNOT_TELL with the passage that decides it. Use on literature reviews, research memos, AI-written answers with references, and before citing anything you did not read. Nothing is sent outside your session.

Heuremen LLC, https://indahl.ai. Source: https://github.com/Heuremen-LLC/indahl.ai/tree/main/claude-plugins/src/source-check

## Services this plugin contacts

None. It runs inside your session; it opens only the sources you point it at.
