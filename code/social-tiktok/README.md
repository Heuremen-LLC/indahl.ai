# SOCIAL, TikTok quarterly report: TikTok's quarterly enforcement report against its EU filings

Live page: https://indahl.ai/social#social-tiktok

Everything here is public. Terms: free to read, run and cite with attribution, no use as training data (LICENSE.txt at the repository root, https://indahl.ai/terms).

Files: `PLAN.md` (the plan and its dated notes), `tiktok_fetch.py` (fetches TikTok's quarterly report files), `tiktok_tick.py` (scores every row and writes the section), `posthoc_daycheck.py` (a check defined after the data, labelled as such, that sizes the days which failed the committed day check), `heuremen_kit.py` (intervals and gates shared by the desks).
