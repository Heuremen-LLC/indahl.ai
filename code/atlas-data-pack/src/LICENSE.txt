2. Epoch AI data (Creative Commons Attribution 4.0)

Licence: CC BY 4.0. https://creativecommons.org/licenses/by/4.0/
Citation: Epoch AI, ‘AI data centers’. Published online at epoch.ai. Retrieved from ‘https://epoch.ai/data/ai-data-centers’ [online resource]. Pulled 2026-10-28.

This applies to:

- json/datacenters.json
- json/electricity.json
- json/scale.json
- csv/datacenters_epoch.csv
- geojson/datacenters_epoch.geojson
- csv/electricity_states.csv
- csv/electricity_meta.csv
- csv/scale_sites.csv
- csv/scale_states.csv
- csv/scale_corrections.csv
- csv/scale_meta.csv

Epoch values are as of the pull date, 2026-10-28. Epoch has updated some sites since.

Changes made by Heuremen LLC: the pack keeps only the rows with Country = United States ({N_EPOCH} of the {N_EPOCH_ALL} rows in Epoch's file at the pull) and only these fields: name, operator, mw, h100e, capex_usd_b and address. Epoch's Name became name and Epoch's Owner became operator. Empty or zero values in mw, h100e and capex_usd_b are blank. The owner text was cut at " #", which removes the tag Epoch puts after the owner (#confident, #likely or #speculative) from {N_TAG} rows. {N_OWNER_EMPTY} rows have an empty owner in Epoch's file and stay blank, as for QTS Cedar Rapids. No owner in the file was only a tag. Trailing spaces were stripped from the address. The columns lat, lon, placed (the text the geocoder matched) and pulled were added. Coordinates were added by geocoding the address, with the US Census geocoder and then OpenStreetMap Nominatim. One geocoded point (Google Papillion) was replaced by a Nominatim point after the geocoder placed it in the wrong state. The scale files add yearly energy and cost figures computed from Epoch's stated power and EIA prices.

Where a file holds both Epoch fields and OpenStreetMap coordinates, both licences apply to it. The files json/electricity.json and csv/electricity_meta.csv are listed here because they carry Epoch site counts and power (epoch_sites, epoch_mw and the unplaced Epoch count).
