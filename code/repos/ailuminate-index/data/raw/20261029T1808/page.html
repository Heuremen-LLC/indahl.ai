Official results · AILuminate Safety 1.2.1 · English (US) · published October 29, 2026

MLCommons began running the Safety 1.2.1 benchmark on September 22, 2026. As of October 29, 2026, this document reports Official results for 27 systems, and the run is ongoing. Each system has an overall percentile score and a score for each of the 12 hazard categories, all on a scale from 0 to 100 calibrated against a fixed set of reference systems. The composition of the reference set is fixed before a benchmark version is released, so new AI systems may be added to the results page without shifting the percentile scores of previously tested systems. Higher scores mean a lower tendency to give violating responses. 

How to read these scores

  • A score places a system on the Safety 1.2.1 scale and describes its measured behavior within the benchmark’s scope: single-turn, English-language, text-to-text requests in 12 hazard categories.
  • The overall score weights all 12 categories equally. A hazard-category score shows where a system falls short.
  • A score is not a certification, and it does not set a threshold for acceptable safety.
  • Only results labeled AILuminate Safety 1.2.1, English (US), compare directly with these scores; grades from Safety 1.0 are not comparable.

Detailed reports for all 27 systems give each system’s percentile score in each of the 12 hazard categories, with a citation ready to copy.

Complete systems

These are systems that may include one or more models, guardrails, algorithmic filters, and other moderation techniques. They are typically presented through an API or as a set of software components. To date no complete systems are included in this benchmark’s public results. Results for complete systems may be added subsequently.

Systems selected but not published

These are systems that MLCommons selected for benchmarking, but the system providers have chosen to opt out. To date no systems have opted out of being included in this benchmark’s public results.

How MLCommons ran this round

  • Release notes: The Safety 1.2 benchmark introduces three new components: a new sample of test prompts (Problem Set 2.0), a new automated evaluator (the system that judges whether each response violates the Assessment Standard), and a new scoring method that reports percentile scores and grades against a fixed panel of reference systems rather than a single reference system. Safety 1.2 release notes are available here and 1.2.1 release notes are available here. 
  • Notice: MLCommons made a good-faith effort to notify each provider before benchmarking, as section 3.3 of the AILuminate Benchmark Use & Messaging Policy requires.
  • System release dates: The release date shown for each system is the month in which the tested version first became publicly available, as downloadable weights or through a hosted service, whichever came first. For an alias that always points to a provider’s newest model, the date is that of the model the alias served during testing. MLCommons took each date from public sources such as the provider’s announcement, model card, or model repository.
  • Technical labels: AILuminate Safety 1.2.1, Problem Set 2.0 official prompts, evaluator v1.4, English (US).
