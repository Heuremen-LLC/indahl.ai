## KNOWN-GOOD
Scout rebuild (scout/RECOUNT.md): all 448 trials' metrics from raw files, the 204 rows of their confirmatory_analysis.csv, the headline
+0.0082 [0.0043, 0.0121] and distributed-minus-single +0.0573 [-0.0091, 0.1250], all to the printed digits; one abstract rounding (upper
bound 0.4 pp printed, 0.347 rebuilt). Read by us in their code: honest agents come first in every condition (agents + new_agents), the
request seed is trial seed x 100000 + round x 1000 + phase x 500 + ordinal, and round 0 shows no feed, so each honest agent's round-0
request is the same prompt and seed in control, single source and distributed sources. Requests run four at a time (parallel_requests 4).

## Addendum 1 (30 Oct 2026, before any U1 count was read; stamp from the commit)
The release holds four conditions per block (control, likes, single_source, distributed_sources), not three: our first script assumed
three from the paper's wording and stopped on every block, printing no counts. Round 0 renders no feed in any condition, so U1 compares the
round-0 text across all four conditions present in each block.
