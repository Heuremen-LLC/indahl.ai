## Readings (all defined after reading the paper; four outcomes; post hoc labels in any write-up)
C1 arm order: the main run always ran none, structure, full in that order (the paper names it as a threat, T5). The rerun counterbalanced
   order. Per (side, model, arm), each rep's WER minus the median of that cell's five reps; then those residuals at position 0 against
   position 2, per model, median and exact sign test. Says whether order moves WER on this subset, holding arm and side fixed.
C2 sign repeat: for each of the four rerun sides and each model, the sign of full minus none in the main run against the sign in each of
   the five reruns (rep k full minus rep k none). Count agreements.
C3 quartile convention: the rerun delta IQR under index quartiles (the printed [-1.9, +2.7]) and under the common linear rule.
