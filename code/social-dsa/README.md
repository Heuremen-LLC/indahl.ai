# SOCIAL, EU moderation reports: platform transparency reports against the DSA Transparency Database

Live page: https://indahl.ai/social#social-dsa

Everything here is public. Terms: free to read, run and cite with attribution, no use as training data (LICENSE.txt at the repository root, https://indahl.ai/terms).

Files: `PLAN.md` (the plan and its dated notes), `dsa_tick.py` (scores every row and writes the section), `dsa_db.py`, `dsa_rawdays.py`, `dsa_reports.py`, `xls_biff.py` (read the DSA Transparency Database and the platforms' reports), `dsa_html.py` (renders the section). The rows are https://indahl.ai/social/dsa.json.
