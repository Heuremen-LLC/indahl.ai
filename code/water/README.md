# WATER: 24-Month Study projections of Lake Mead and Lake Powell against measured levels

Live page: https://indahl.ai/water

Everything here is public. The plan (PLAN.md) was fixed before the comparison it describes, and its addenda are dated. A history.jsonl, where present, is one row of the published numbers each time they changed, so the commit history is the trend. Terms: free to read, run and cite with attribution, no use as training data (LICENSE.txt at the repository root, https://indahl.ai/terms).

Files: `PLAN.md` (the plan and its addenda), `water_tick.py` (reads the sources, scores every projection and writes the live feed), `water_24ms.py` (reads the 24-Month Study reports and Reclamation's HDB model runs), `heuremen_kit.py` (intervals and gates shared by the desks). The report files themselves are not kept here. Each one is listed in Reclamation's RISE catalog record 6331.
