# SWEEP: Ivy League documents on AI in teaching and learning, 2023 - Oct 2026

Swept 25 Oct 2026. English only. Type A = institutional (committee/task force report, policy, teaching-centre guidance, university-run survey). Type B = empirical study by faculty or teaching centre.
Method: web search plus page fetch. PDFs read as extracted text. "UNREAD" = document body not opened (fetch blocked 403/certificate error, or only a search-result snippet seen); fields marked from the snippet are labelled as such. "Data/instrument" = released with the document. Funding/ack column quotes the document where the document was read; "none found" means searched in the text read.
Not recorded: findings, quality judgments. Student-newspaper and outside-organization surveys are in the exclusions list at the end, not in the tables.
