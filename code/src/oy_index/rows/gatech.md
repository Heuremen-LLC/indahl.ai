## Bones read (25 Oct ~12:50): Socratic Mind paper, arXiv 2509.16262v2 (same study as the TKL paper), full text
- Design (paper's words): "quasi-experimental". "A total of 579 students enrolled in CS1301 were randomly assigned to complete the AI-based
  assignments for either Unit 3 or Unit 4. These optional assignments ... offered students the opportunity to earn 3 extra credit points."
- Uptake: "147 students never attempted the extra-credit AI assignment, and an additional 89 students submitted their responses after the
  assignment deadline." Final sample 173 (survey 171: Unit 3 n = 81, Unit 4 n = 90). 173 of 579 = 30%, self-selected among the assigned.
- Learning result (DiD table, quiz model): Post*Treatment B = 3.300, SE 1.373 -> t = 2.40 (paper marks *). Test model: Post*Treatment
  B = -3.017, SE 2.631 -> t = -1.15, CONSISTENT with zero on the tests. The abstract reports the quiz gain, not the test null.
- Check owed (CANNOT_TELL without data): in both models the Post Scores SE equals the Post*Treatment SE (1.373/1.373; 2.631/2.631), and the
  quiz-model interaction B (3.300) equals the test-model Post B in size (-3.300). Can arise in a balanced design; needs the data to tell.
- Comparison: abstract says "compared to those who did not" use the tool; with 30% optional uptake the user/non-user comparison carries
  selection, while the random unit assignment covers only which unit was offered. No funding or data-availability line found in the text.
- Ruling: pilot results READ -> gatech counted as MEASURED-PILOT (n = 173 of 579 assigned; quiz DiD +3.3, tests -3.0 not resolved).
- Referee (25 Oct): numbers confirmed. Added: abstract also claims "particularly benefiting students with lower baseline achievement"; the paper's
  funnel does not add up (579 - 147 never attempted - 89 late = 343, printed "Among the remaining 293 students"). SE-equality flag stands: a
  simulated balanced 2x2 gives interaction SE ~1.41x the main-effect SE, not equal; unit-stacked design is unusual -> CANNOT_TELL without data.
