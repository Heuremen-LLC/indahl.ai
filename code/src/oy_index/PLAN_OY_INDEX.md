# Recount Matrix: Learning Research - PLAN (committed before any claim is priced; 25 Oct 2026)

## Scope
Empirical studies and policy documents on AI/LLM use in learning, 2023-now, English only. Universities (public IN), journals,
think-tank and multilateral policy (UNESCO, OECD) [DROPPED by addendum 3: schools only]. Standing exclusion (cut list DOES NOT apply to OY: Wayfinder 25 Oct ~10:40 "no cut list for this one"): government institutions and government-agency/defence grants,
any country -> CARD ONLY (counted, never silently dropped). Companies -> CARD ONLY. Cut list: NOT applied in OY.

## What each document gets (columns)
1. DATA RELEASED: per-item / per-student data, instrument, codebook (yes / partial / no). No data = no recount, card + pricing only.
2. RECOUNT (data released): our code, their files, plan per study before reading data, known-good copy, intervals, four outcomes.
3. CLAIM INVENTORY: every numeric claim (with n, denominator, source), every empirical claim stated without a number or citation,
   every hedge, every recommendation and the evidence item it names (or none). Verbatim quotes with offsets.
4. SOURCE CHECK: each numeric claim traced to its stated source; the source read in full; mismatch = row.
5. PRICING AGAINST PRACTICE: a claim about what AI does/cannot do in learning is set beside documented current practice
   (a peer-reviewed or preregistered study, or a vendor/industry document read in full, each with its own n and date). Outcomes:
   ABOVE (claim exceeds the record) / BELOW (claim understates it) / CONSISTENT (within the record, printed as a bound) /
   CANNOT_TELL (no record reaches it). A claim with no number and no test is "no testable claim": its own column, never a verdict.
6. MOTIVE IS NEVER A ROW: why an author wrote something is not measured and never appears.

## Rules
Quotes only, no adjectives. Every count recounted by Bones by hand before it enters THE register. Referee (read-only Sonnet, raw files)
every three rows. Selection: every candidate the sweep finds is logged with the reason it was kept or cut (no cherry-picked targets;
C-001 MIT entered by Wayfinder's naming and is labelled so). Internal name only in chat; files use the neutral title.

## Sweep order
ERIC API -> arXiv cs.CY/cs.HC education -> EdArXiv/OSF/ICPSR/Dataverse/Zenodo replication packages -> open-access journals
(Computers & Education, BJET, IJAIED, L@S, EDM/AIED) -> policy (UNESCO, OECD, university committee reports like C-001).
