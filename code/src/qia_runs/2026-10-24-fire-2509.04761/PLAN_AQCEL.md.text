## The question (triage): their 0.99 vs 0.46 gap has no control separating the fewer-CZ circuit from a nearly-uniform guess.
Free part, done before the job (zero QPU, dry_run_aqcel.text): the ideal output has 4 strings (0.627 / 0.141 / 0.131 / 0.101);
uniform over all 64 strings scores F = 0.053; uniform over the 4 support strings scores 0.853; the CZ-removed control (below) scores 0.272

## Construction (our code; python -I; nothing of theirs executed)
aqcel_rebuild.py: 1-step QPS circuit rebuilt from the released generator's construction (eps 0.001, gL 2, gR 1, g12 1, phi->ffbar on,
registers p0 p1 h1 e phi a b, measure p0 p1); Aqcel decomposition (RCCX ladder on ancillas + singly-controlled U), adjacent-pair
cancellation, control-state removal rules (v1 judge rules), and for v2 the CX-pair removal under the paper's three sufficient conditions.
Difference from theirs (stated): control-state probabilities are EXACT (statevector of the optimized prefix), not sampled shots; we do not
emulate the label manager (with exact probabilities it only skips reads). arms.py: four arms, threshold 0.01 (Table 2 main entries):
  Q    original circuit             -> fez, generate_preset_pass_manager(optimization_level=3, seed_transpiler=11): 199 CZ (paper 246)
  V1   our Aqcel-v1, thr 0.01       -> 49 CZ (paper 48)
  V2   our Aqcel-v2, thr 0.01       -> 31 CZ (paper 36)
  CTRL the V2 ISA circuit with every cz deleted (same physical qubits, same single-qubit layer, same measurements) -> 0 CZ
  noiseless F vs ideal: Q 1.0000, V1 1.0000, V2 1.0000, CTRL 0.2718. Measured physical qubits: Q [111,109,112,98,14,91];
  V1 [25,142,84,5,50,6]; V2 and CTRL [25,142,84,3,50,6] (dry run 16:52Z record). CTRL is CZ-removed, NOT duration-matched (depth 48 vs 95).
Readout: CAL0 / CAL1 (all 13 measured physical qubits prepared 0 / 1) inside the same job; tensored per-qubit correction (stands in for
their M3, whose default calibration is also per qubit); quasi-distribution not renormalised.
Job: ONE SamplerV2 job, 24 pubs = 4 rounds x [CAL0, CAL1, Q, V1, V2, CTRL]; arms 5,000 shots per copy (20,000 per arm), calibration
2,500 per copy; 100,000 shots. Circuits frozen in circuits_aqcel.qpy (sha256 in meta_aqcel.json) and submitted as built (no runtime
transpile). Options set explicitly: twirling.enable_gates False, twirling.enable_measure False, dynamical_decoupling.enable False;
rep_delay = backend default (theirs 0.0005 s; stated difference). Estimate 100,000 x 0.30 ms + 3 s = 33 s; HARD CAP 60 s (fire_aqcel.py
refuses above it); usage_remaining_seconds 2761 at the dry run (stop if < 600). Records saved before and after the job. One restart on an
IBM-side ERROR, then HOLD.

## Readings (analyze_aqcel.py, fixed now)
F_k = Hellinger fidelity (their eq. 1) of arm k's readout-corrected output vs the exact ideal of the ORIGINAL circuit; also the raw F.
95 % percentile bootstrap, B = 2000 (arm counts multinomial, calibration binomial per qubit). D3 = F_V2 - F_CTRL; D2 = F_V2 - F_Q.
Drift guard: between-copy variance of F (4 copies) over single-copy shot variance > 5.42 (chi2_3 0.999 / 3) flags that arm.
PRIMARY outcome, rules applied in this order (four outcomes of the triage):
  CANNOT_TELL  drift flag on V2 or CTRL
  GAP          D3 upper < 0 (control beats Aqcel-v2)
  CANNOT_TELL  D3 lower <= 0 (control scores as high as Aqcel-v2: small output space)
  GAP          F_V2 upper < 0.985 (Aqcel-v2 below its printed 0.99 beyond the interval; 0.985 = rounding edge of "0.99")
  GAP          D2 lower <= 0 (no advantage over Qiskit-only)
  CLEAN        D2 interval overlaps [0.52, 0.54] (their printed 0.99 - 0.46 gap reproduces, with the control far below)
  FILL         otherwise (advantage beyond control and Qiskit-only holds; its size differs from the printed 0.53: we print it with width)
SECONDARY (reported; ABOVE / BELOW / CONSISTENT vs printed band, CANNOT_TELL if that arm's drift flag is set):
  F_V2 vs [0.985, 0.995]; F_V1 vs [0.985, 0.995]; F_Q vs [0.455, 0.465]. Three secondary readings at 95 % -> ~5 % false resolution each.
Descriptive, not scored: raw F per arm, per-copy F, calibration errors, CZ counts, record changes on the used qubits during the window.

## Four outcomes, what each would say
CLEAN: today's fez with our rebuild gives their printed 0.99 / 0.46 gap within width, and a CZ-free circuit on the same qubits does not.
FILL: the Aqcel-v2 advantage holds beyond the control, at a size we print with its width (their table has none).
GAP: Aqcel-v2 scores below 0.99 beyond the width, or does not beat Qiskit-only, or the control beats it.
CANNOT_TELL: the control scores as high as Aqcel-v2, or drift beyond shot noise; the deciding run is a repeat with duration-matched control.
It cannot say anything about their run day, their M3 calibration, their v1 circuits (ours differ), or the 2-step results.
