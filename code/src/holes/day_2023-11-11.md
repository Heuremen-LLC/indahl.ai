all within 60 min of NIST gap starts 10:27-11:32). M5 = 10, all from the blip train. In effect this is 2 events: one real lock loss

## Verdict (facts only)
- H1 side: explained. It is a routine lock loss (07:08) plus a known BS-camera software crash loop (11:26-15:23), both in the LHO alog.
  No quake, windstorm or ground motion is behind either one.
- NIST side: not explained. Two degraded windows (11-11 07:24-11:33 and 11-12 08:28 to 11-13 01:11), no notice, no public outage found.
- Link: none found. No common physical cause. L1 was unaffected. The NIST degradation came back the next day while H1 stayed locked.
  The 07:08 -> 07:24 proximity is one pair, 16 minutes apart.
