# A Readout's Kick Is a Turn: data and verification code

Data, plans, analysis code and outputs for "A Readout's Kick Is a Turn: Giving It Back, and How Long the Correction Lasts" (K. Indahl, Heuremen LLC). The runs on ibm_kingston and ibm_marrakesh behind the paper, and the first fire of the clock that measures how long the correction lasts (folder `readout-correction/clock/`).

- `A_Readouts_Kick_Is_a_Turn_code_and_results.zip` (2.5 MB): plans, code and committed outputs.
- `A_Readouts_Kick_Is_a_Turn_raw.zip` (19 MB): the raw arrays (`.npz`) behind the figures.

Same files as the Zenodo record https://doi.org/10.5281/zenodo.23843468 . The page: https://indahl.ai/darkwave . The code as it ran, in public: https://github.com/Heuremen-LLC/indahl.ai/tree/main/code/readout-correction
