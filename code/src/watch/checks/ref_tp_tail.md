## Log the row, at the moment

Before you answer, write the row. Afterwards is the in-sample fit.

```
python3 ~/bones-forge/watch/tp_score.py --add \
  --lesson I|II|III|none --caught BEFORE|AFTER --by bones|machine|wayfinder \
  --what "one line"
```

`BEFORE` only if the catch happened before the reading was stated. `by machine` when a gate or an
assert caught it. `by wayfinder` when he caught it.

never new. Then re-read with the corrected none and give the number again. "It holds" is a legal
answer if you say what you checked. So is LA NADA: the question is right and the data cannot answer
