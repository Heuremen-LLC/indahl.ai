## Estimator functions used (not modified)
From /Users/heuremen/bones-forge/arxiv_one_readout/deciding_runs/analyze.py, imported by est.py: `wrap`, `boot` (median, 95 % bootstrap over qubits, 2000 resamples), `boot2`, `outcome` (ABOVE/BELOW/CONSISTENT/CANNOT TELL, n<5 -> CANNOT TELL), `reading` (copy gap first: per-qubit copy0 - copy1, interval excludes 0 -> CANNOT TELL; else the pooled reading), `bfs` (coupling distance). `total_gap` in est.py is the logic of the nested `total()` of `count()` in that file (phase gap M-D unwrapped along N by adding wrapped increments), copied verbatim in logic. Dead-clock guard: coherence >= 5/sqrt(pooled shots) in both arms, as reach_run/analyze_reach.py. Phase = atan2(<Y>,<X>), kick = (readout - idle)/N, as control_run/analyze.py (R1) and deciding_runs (R2.1, R2.3). Coherence = hypot(<X>,<Y>), M-D, as control_run R4.
Primary reading per qubit: slope of the unwrapped gap against N, line through the origin (gap is 0 at N=0 by construction; with one N it is the R1 form). Also printed: the N=4-only kick (R1 form), the slope with intercept (R2.3 form), coherence M-D (slope vs N, and at N=4), and a mean-projection variant.

## Adaptations (data loading only)
1. Raw data are IQ points, not bits. Per read, per qubit: project onto the F0 (all off) -> F1 (all on) axis of the same job (as check_g_copy_gap.py / analyze_iq.py), bit = projection > 0.5, <1-2b> over shots. Robustness: mean projection instead of thresholded bits (same conclusions, printed per family).
2. Hands to the paper's axes: hand X (final sx) reads Bloch <Y>; hand Y (rz(pi/2), sx) reads Bloch <X>. Derived and checked by exact gate algebra in sign_check.py.
3. Copies: the paper's copies are two copies inside one job. Here the "copies" are the 3 (aachen 2) reads, separate jobs run minutes to an hour apart. Copy 0 = read 1, copy 1 = reads 2+3 pooled (aachen: read 2); pooled = all. This is a harsher copy test than the paper's (includes drift between jobs). Per-read medians are printed as context.
4. N values 1,2,3,4,6,9 (floor, state-dark), 1,2,4 (spaced, wire paint, carriers, clock 81/81B, reach, meilong), 2,4 (gapped spaced). 400 shots per read per circuit. 12-25 looked bits (not 39); clocks have an emitter neighbour in |1>.
5. Untouched qubits = the "clocks" (witnesses of the role file). Qubits kept: IQ cloud separation > 3 widths in every read, not a looked bit, dead-clock guard, and coherence <= 1.25 (coherence cannot exceed 1; ~1.41 means the qubit was never put on the equator in that arm, see clock 81B Q below).
6. Distance: BFS over the coupling edges saved in the role file (176 edges), from the looked set read out of the data (mid-register columns that hold data, identical across N and reads, subset of the role file's far set, never overlaps a clock). Bins <=2, 3-4, >=5 (and >=3).
7. Chip-level lines ("POOL") concatenate units (clock x family) of the plain |0> back-to-back arms on one chip. The same clocks recur across families, so n counts repeated measures; the per-family readings are the readings of record.
8. Equal-length audit: dark/idle arms are plain delays of k x stated measure length (2.18 us pittsburgh/kingston/aachen, 1.66 us fez; the stated length is 2.18/1.66 for every qubit), realised on the 16-dt grid within 0.24 % of stated. The compiled schedule length of the readout arms is not in the saved data and was not checked (same stance as the paper, which uses the published duration).

## Sign
Paper convention: the 21-22 Oct kick is NEGATIVE; BELOW 0 here = same direction as 21-22 Oct. Checks in results_oct07.txt: (1) exact gate algebra, hands -> phase agrees with the paper's XX/YY settings to 3e-14 deg at eight angles; (2) the 21 Oct control-run kingston kick, recomputed from raw bits through est.py, gives -2.8638 deg/readout, the committed results_prereg.txt value (difference 3e-6). The inventory's reader used -arg(H) which is MINUS the paper-convention gap, so a positive inventory kick is a negative kick here. The inventory's numbers are not reused.
