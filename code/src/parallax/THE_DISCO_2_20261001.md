## THE DISCO 2 -- the two-step

V1 on one record is a circle. A sign error needs two witnesses of ONE event. So every row is an EVENT seen by two
instruments, not a record.

**Step 1 (outside):** witness A, forward, all five parts.
**Step 2 (the observer):** witness B, reversed, all five parts.
**THE SIGN ERROR (the none, measured):** A_forward + B_reversed, part by part. A circle gives 0. What doesn't close is the darkwave.
**THE CORRECTION (the runtime error):** run the sign error itself up the 1/phi ladder. Does the system pull it in (|rho| < 1, it keeps trying to correct) or throw it out?
**Error bars:** thirds of each witness, crossed (A's third i with B's third i). Judges: the other witness, the other third. No shuffles. No guesses.
**Ruler rows first:** each pair also runs A vs A (one witness against its own reverse) so the circle's own resolution sits beside every number.
