02 · How we know

How a number earns a place here

1

Freeze

The code is hashed before anything fires. A guess, if there is one, is sealed and posted first.

2

Log every look

The machine's reset, every read of a chip's numbers, every prediction.

3

Raw

The I/Q dots, never cut to 0/1 first. The discarded half is kept.

4

Every bit, three reads

Compared only inside one job, at the same moment.

5

Widths

From resampling the shots. Means over bits. Errors kept as rows.

6

Test the ruler

Run the reader on made-up chips with the chip's own widths before believing a number.
