“Event-Ready Bell Test Using Entangled Atoms Simultaneously
Closing Detection and Locality Loopholes”

W. Rosenfeld, D. Burchardt, R. Garthoff, K. Redeker,
N. Ortegel, M. Rau, and H. Weinfurter,

Background
----------

These files preserve experimental data and material that were
originally made available through the website

http://bellexp.quantum.physik.uni-muenchen.de

operated by the Experimental Quantum Physics group at
Ludwig-Maximilians-Universität München.

As described in the publication and its Supplemental Material,
a public Bell-test measurement run was started on 14 June 2016.
During this run, individual experimental events were transmitted
to a central server and the incoming data and current evaluation
were made publicly available in real time through the website.

The original university-hosted web service was subsequently
discontinued and is no longer publicly accessible.


Preservation
------------

In 2026, the original data and Bell-server files were recovered
from the original experimental computing infrastructure at
Ludwig-Maximilians-Universität München.

This Zenodo record was created to restore persistent public
access to the experimental data referenced by the publication.

The original downloadable data archives included in this
deposit have been preserved without modification.

Historical website
------------------

The former website provided, among other information:

- the current experimental state;
- individual measurement events;
- evaluation of the accumulated Bell-test data;
- downloadable experimental data.

Because the experiment is no longer running, the real-time
functionality of the original website is not reproduced here.
The screenshots/static material are provided for historical
documentation.


Data provenance
---------------

The data contained in the original ZIP archives are the files
that were provided for download through the Bell-test website.
They have not been reprocessed or reformatted for this Zenodo
deposit.

For details of the experimental apparatus, data format,
statistical analysis, event selection and Bell-test protocol,
please refer to the associated publication and its Supplemental
Material.
