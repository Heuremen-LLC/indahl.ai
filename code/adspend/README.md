# SOCIAL, political ad spend: Google's political ad library against FEC filings

Live page: https://indahl.ai/social#adspend

Everything here is public. Terms: free to read, run and cite with attribution, no use as training data (LICENSE.txt at the repository root, https://indahl.ai/terms).

Files: `PLAN.md` (the plan and its dated notes), `adspend_tick.py` (reads Google's political ad library and FEC bulk filings, matches committees, scores every row and writes the section). The rows are https://indahl.ai/social/adspend.json.
