Division: HERMES

Papers state where their code is. Does the link still lead there?

We read every arXiv paper in five categories whose abstract points to GitHub, GitLab, Hugging Face, Zenodo or Bitbucket, and keep each link the abstract or the arXiv comment gives. Every link is requested and read again every seven days. A link counts as rot when the page is gone or the host name no longer exists. A host that blocks us or times out is counted apart and is never rot. Every link is also requested from an independent network, the GitHub runner network, and a link that one network reads live and the other reads gone is counted as blocked and never as rot.

Ten control links run before each pass, five that must be live and five that must be gone. If any control reads wrong, every row reads cannot tell. For links that lead to a GitHub repository we also ask whether anything is there: the repository check below counts repositories with no commits. We do not read the code. Links that appear only in the full text of a paper are not reached. Rules were committed before the first link was checked.
