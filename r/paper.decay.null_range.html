The line the number is read from:

Calibration check: the published null procedure, run on my simulated pure-exponential data, returns 48.6-50.2 %, matching the true simulated share. So the published null was unbiased for this chain. The like-for-like null is 48.6-54.2 % across all jobs and variants (main variant 49.2-53.6 %). The upper end is fez and marrakesh (lower levels, so the idle-in-0 floor matters slightly) and is still far from the observed values.
