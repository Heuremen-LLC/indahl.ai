What it is: CHANGE headline: the number comes from https://indahl.ai/change/live.json, field ["lifespan", "Google, names with preview", "under180"]. Refresh cadence 2.5 h, read stale after 3.75 h. A new value row is written only under the plan's stated rule, read on the fields listed in the row, or when the outcome flips. The lifespan count has no width. The plan's stated rule is per dated row: NEW, MOVED_LATER, MOVED_EARLIER, REMOVED or DATE_ADDED (PLAN.md line 11). A value row is written when the count under six months or the count of dated preview models changes, which is when such a row enters or leaves, or when the held-or-moved test flips.
