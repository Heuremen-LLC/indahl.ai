What it is: STEO headline: the number comes from https://indahl.ai/steo/live.json, field ["cells", {"series": "WTI", "cell": "all leads"}, "share"]. Refresh cadence 48 h, read stale after 72 h. A new value row is written only when the outcome flips or the headline number moves outside the interval the previous value row printed. Moves inside it stay live on the page. PLAN.md (Rules) states a moving-block bootstrap 95 percent interval over outcome months and the outcome rule against the stated 95 percent. The value rows steo.cell.wti.all and steo.cell.hh.all hold the shipped reading.
