# SOLAR reproduce kit

Heuremen LLC · https://indahl.ai/solar · https://indahl.ai/reproduce

This kit recomputes the SOLAR headline number and its outcome label with the desk's own code, from what the kit holds, with its network proxies pointed at a closed port.

## The command

```
python3 run.py --check
```

Needs Python 3.9 or later and nothing else. It prints one line of JSON and checks it against expected.json. The line it must print has sha256 `336e3ae79281b594f30b1ad6497dcf7103702986d2f9ee016b672e787bd5fa9c`.

## What it reproduces

The headline as the live feed https://indahl.ai/solar/live.json served it at the feed stamp 2026-11-10T20:42:24Z, read by us at 2026-11-10T23:45:56Z. The feed bytes had sha256 `568bb531c40726e8472a3d7eb7905f50c16f1d247384a767e3fe746634d0480b`.

- number: 4 of 8
- value: 0.2683
- interval: 0.2086 to 0.3225
- outcome: ABOVE

The live page can move inside the interval between releases. Each move outside it, or a change of label, gets a new row in our ledger, and a release is refused until this kit reproduces the number that row covers. The headline fields are the ones the ledger reads (`kit.json`, headline).

## Inputs

Not included. The GFZ file the desk reads for Kp also carries sunspot numbers under CC BY-NC 4.0 and F10.7 from DRAO and NRCan, which the data pack leaves out, so this kit carries no copy of the source data. MANIFEST.json lists each input file the desk's scoring read, with its size, its sha256 and the time it was last written. We keep those exact files and rerun this kit on them before every release.

The input files are what the desk kept from its reads of the sources, with the time of each read where the desk records it. To check them, read the sources below again and compare. With a copy of the input files, `python3 run.py --check --inputs DIR` reruns the kit on them. A file whose sha256 differs from MANIFEST.json is named and the run stops. Sources change, so a later read can differ from ours.

- NOAA SWPC Report and Forecast of Solar and Geophysical Activity as first published, ftp://ftp.swpc.noaa.gov/pub/warehouse/ (data/raw/warehouse), with our own dated copies in data/snapshots.
- NOAA SWPC Edited Solar Events and daily indices, ftp://ftp.swpc.noaa.gov/pub/indices/ (data/raw/indices and the event lists).
- GFZ Potsdam Kp, https://kp.gfz.de/ (data/raw/gfz, the file Kp_ap_Ap_SN_F107_since_1932.txt).

## Code

The desk's own scripts, byte for byte, under code/. They run in this order: code/solar_tick.py --offline. The same files are in the public repository under code/solar/.

## Files

- kit.json: the steps, the output file and the headline fields.
- run.py: the command.
- expected.json and expected.sha256: the line run.py must print.
- published.json: the headline as the live feed served it when this kit was made.
- MANIFEST.json: every input and code file with its sha256.
- desk/: the desk scripts the extract follows, where the kit runs an extract.
- SHA256SUMS.txt: the sha256 of every file in this folder.
