HPT · Hospital Price Files Against the Rule

12 of 506

hospital price files linked from hospital websites do not open as data. We read 1,921 hospital websites for the file the federal rule asks for.

Division: HERMES

Is the price file where the rule says it is?

The federal hospital price transparency rule asks each hospital to publish a machine-readable file of its standard charges, and to put a small text file named cms-hpt.txt at the root of its website that links to it. For every hospital website listed in Wikidata we check three things in order: the text file at the root, whether the file it links to opens as data, and whether that file starts with the template header names.

Named here and want to answer a row? Respond

Wikidata lists clinics and parts of health systems, and a hospital that belongs to a system can have its file at the system's domain, so a missing file at a hospital's own domain can be correct. Our full read of ten rows is in the plan. For that reason the first step is never scored above CANNOT_TELL. Steps two and three are scored against a claim of zero disagreement: ABOVE when the lower end of the 95 percent interval is above 10 percent, CONSISTENT when the upper end is below 5 percent. Websites we could not open, that refused our user agent, or that are a page on a shared site are counted apart. JSON and zip files are not checked for the header because their key names can sit after the data. Every failing row of steps two and three that has been read in full is listed with what the read found. Failing rows not yet read in full are counted above the tables as awaiting a read in full.
