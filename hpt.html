HPT · Hospital Price Files Against the Rule

Division: HERMES

Is the price file where the rule says it is?

The federal hospital price transparency rule asks each hospital to publish a machine-readable file of its standard charges, and to put a small text file named cms-hpt.txt at the root of its website that links to it. For every hospital website listed in Wikidata we check three things in order: the text file at the root, whether the file it links to opens as data, and whether that file starts with the template header names.

Named here and want to answer a row? Respond

The first step is not a compliance rate. Wikidata lists clinics and parts of health systems, and a hospital that belongs to a system can have its file at the system's domain, so a missing file at a hospital's own domain can be correct. Our hand check of ten rows is in the plan. For that reason the first step is never scored above CANNOT_TELL. Steps two and three are scored against a claim of zero disagreement: ABOVE when the lower end of the 95 percent interval is above 10 percent, CONSISTENT when the upper end is below 5 percent. Websites we could not open, that refused our user agent, or that are a page on a shared site are counted apart. JSON and zip files are not checked for the header because their key names can sit after the data. Every failing row of steps two and three was opened by hand and is listed. Plan, addenda and code.
