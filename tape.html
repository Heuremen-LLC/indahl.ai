Division: HERMES

A record of what was published, in the order it was published

Every few minutes we hash every public page and every live feed and add one line to a chain. Each line carries the hash of the line before it, so changing an old line changes every line after it. Each run also writes a beacon value built from the newest drand round, the feeds of that run and the previous line. Nobody could have known it before those inputs existed, and anyone can recompute it. Every few hours the chain is stamped with OpenTimestamps, which ties it to Bitcoin’s timeline. We hold no coin and run no mining.
