Version Read

arXiv PDF as served 12 Nov 2026. The version number was not recorded.

What the Paper Prints

“Posteriors on the EOS parameters obtained using emulators for the 5-parameter model are shown in Fig. 2.” Section 3.2

“Ksat = 240+5336 ... Lsym = 45+6423 ... Ksym = 215+24179 ... c2s (3n0) = 0.68+0.290.34 ... c2s (5n0) = 0.59+0.380.52” Figure 2, as extracted from the PDF text

What the Paper Shows Elsewhere

“Ksat (MeV) 238.10+53.50−34.70 239.60+52.65−36.18” Table 2, Ksat, columns Emulator and Full Solver

“Ksym (MeV) −209.3+228.5−83.1 −214.7+240.8−78.9” Table 2, Ksym

“c2s(3n0)/c2 0.65+0.31−0.32 0.68+0.29−0.34” Table 2, c2s(3n0)

“c2s(5n0)/c2 0.62+0.35−0.55 0.59+0.38−0.52” Table 2, c2s(5n0)

Rounded to the figure’s digits, the values printed in Figure 2 (90% intervals) equal the Full Solver column of Table 2 for all five parameters. The Emulator column does not match, for example Ksym −209.3 against −214.7 (Full Solver) and −215 (Figure 2).
