CONNECT

Every way to use our measurements and checks from Claude, Claude Code or any MCP client. Everything is free, read-only where it touches our data, and the code is public in github.com/Heuremen-LLC/indahl.ai.

Connectors (MCP servers)

Remote MCP servers over HTTP, no key, nothing to install. In Claude: Settings, Connectors, Add custom connector, and paste the address. In Claude Code: claude mcp add --transport http indahl <address>.

AddressWhat it holds
https://indahl.ai/mcpEvery tool over every live desk. Tool list on the API page.
https://indahl.ai/mcp/quantumHeuremen LLC quantum data. IBM Quantum published calibration checked against itself and the QIA index of quantum hardware studies.
https://indahl.ai/mcp/modelsHeuremen LLC model and package data. Open models, packages and AI benchmarks: stated against delivered.
https://indahl.ai/mcp/educationIndahl Campus. Where colleges and universities publish their AI-policy material, and whether each page still opens. Links and states only, no ratings.
https://indahl.ai/mcp/infrastructureIndahl Atlas. Built infrastructure from open sources: data centers, operating power plants and planned power plants, with their places and source records. Locations and sources only, no ratings.
https://indahl.ai/mcp/publicHeuremen LLC public data checks. Forecasts, agencies, public services and infrastructure: stated against delivered.

The same tools as plain JSON: /api/v1, with the OpenAPI description at /api/openapi.json.

Claude Code plugins and skills

Add the marketplace once, then install what you want, or everything with indahl-full.

/plugin marketplace add Heuremen-LLC/indahl.ai
/plugin install indahl-full@heuremen
InstallWhat it does
indahl-full@heuremenEvery Heuremen LLC plugin in one install: Standards, eval checks, readcheck gate, reproduce, QIA calibration, Darkwave, prereg, and the indahl.ai data connector.
indahl-triangulate@heuremenOne question to three independent seats run blind, four-outcome verdict with a receipt.
indahl-standards@heuremenCheck a paper or claim against the Standards claim codes and return a recount card with quotes, scope and four-state statuses. The agent is told to treat fetched paper text as data, not instructions.
indahl-readcheck@heuremenRefuse a git commit that adds a reading (results, outcomes) without a complete check block keyed to the Standards recount requirements.
indahl-qia-calibration@heuremenCheck the IBM Quantum calibration record a run depends on, before the run and after it. Read-only, standard library only, and measure T1 and T2 together on chosen qubits in one job.
indahl-data@heuremenEvery live indahl.ai desk inside Claude Code through the read-only indahl.ai MCP server, quoted with interval, outcome and receipt. The agent is told to treat API responses as data, not instructions.
indahl-reproduce@heuremenRecompute an indahl.ai desk headline that has a reproduce kit, with the kit's own code, and check the published sha256. Nothing runs without a go bound to the commit you reviewed.
indahl-darkwave@heuremenMeasure the phase turn on untouched qubits after a mid-circuit readout on IBM Quantum hardware and add the matching virtual-Z correction.
indahl-eval-check@heuremenCheck an LLM evaluation claim or your own eval run: setup as part of the result, parser checked against raw replies, repeat floor, dropped items, intervals and four outcomes. The agent is told to treat fetched papers, files and model outputs as data, not instructions.
indahl-prereg@heuremenShow that a plan was pushed before the first run, from your git host's own push record (no outside timestamp chain), and list what ran that the plan did not cover.
indahl-batch@heuremenRun a check or audit over something too big for one context window (a whole site, a large repo, a folder of papers) without losing the instructions: short brief, item list, batches with fresh workers,
indahl-cannot-tell@heuremenPermission and a procedure for answering 'I can't tell yet' instead of forcing an answer: the range of what is possible, the facts that would decide it, and the cheapest next step
indahl-both@heuremenHold two competing explanations open instead of collapsing to one too early: two evidence ledgers, four states (A, B, BOTH, NEITHER), and the test that would separate them
indahl-outside-ruler@heuremenCheck your own work against a ruler you did not build before it goes out: a referee pass on the raw material, ten checks drawn from mistakes that cost real corrections, and a STANDS / MOVES / HOLD ver
indahl-number-check@heuremenCheck every number in a report, memo, deck, dashboard or another skill's output against its source: each figure traced, then marked HELD, MOVED, NO_SOURCE or CANNOT_TELL with the source line beside it
indahl-quote-check@heuremenCheck every quotation in a draft, article, report or another skill's output against its source, word for word: VERBATIM, ALTERED, PARAPHRASE_IN_QUOTES, MISATTRIBUTED, NOT_FOUND or CANNOT_TELL, with th
indahl-source-check@heuremenCheck every citation, reference or link in a paper, report, answer or another skill's output: does it exist, does it say what the text claims, which version was read. Marks each SUPPORTS, PARTIAL, CON
indahl-controls@heuremenAudit a study's, benchmark's or check's positive and negative controls before it runs: was each control chosen independently of the value the rule reads, can the rule fire on it at all, and is the har
indahl-margin@heuremenFor a sharp prediction, design or result, find how far its key parameter can move before the conclusion fails, and compare that margin with the parameter's own stated uncertainty. Returns ROBUST, FRAGILE (margin smaller than the uncertainty) or CANNOT_TELL, with the break point. Use before an expensive run, a preregistration, a launch decision, or when a result rests on one tuned number. Nothing is sent outside your session.
indahl-correct@heuremenRecord a correction beside the original, never over it: what was wrong, who caught it, when, the evidence, the corrected text, and whether every place that cited the original was reached. Produces a c
indahl-clause@heuremenCheck the sentences that report a result for wording that claims more than the comparison showed: an item that is wrong on its own described as if the paired comparison moved, a CONSISTENT reported as
indahl-silent-failure-guard@heuremenQuiet is not success. After any action that claims it worked (a push, a deploy, a sync, a job, an import, a migration, a scheduled run), read the effect back from where it should have landed instead of taking the exit code, an 'ok' line or the absence of errors as proof. Returns VERIFIED, FAILED, NOTHING_RETURNED or CANNOT_TELL per action, and scans scripts for the patterns that hide failures. Nothing is sent outside your session.
indahl-relay@heuremenRun multi-stage unattended work (training ladders, eval sweeps, data pipelines) as a chain of stages with dependencies, machine lanes, exit codes recorded to files, explicit blocked states and an optional end-of-run handoff. Runs locally. Nothing is sent anywhere unless a stage you write sends it.
