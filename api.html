Our measurements as tools

Every live measurement on this site can be read by an agent or a script, with no key and nothing to install. Each answer carries its source page, the time it was read and the terms. Outcomes are above, below, consistent or cannot tell, relative to what was stated. Nothing here writes anything.

Add it to an agent

The MCP server is at https://indahl.ai/mcp and speaks the Model Context Protocol over HTTP. In Claude Code:

claude mcp add --transport http indahl https://indahl.ai/mcp

Any client that takes a remote MCP server can use the same address. Start with list_divisions.

Tools

ToolReturns
list_divisionsEvery division with a line on what it measures and its page.
time_serversPublic time servers against their own stated error bounds, live, from two networks. Optional server filter.
dns_filtersPublic DNS filters against fresh malware and phishing listings, live: share blocked and counts by checkpoint.
coin_claimsRavencoin whitepaper statements against the chain record, live, with the quote and outcome.
ibm_calibrationThe calibration IBM publishes for each processor, mirrored every few minutes. Optional processor filter.
find_studySearch the List of indexed quantum or language-model studies, with receipts.
bench_resultsFaults and Guards rates on open models, per round, with intervals.
model_claims_roundThe live round that reruns an open model's stated results.

The same tools as plain JSON

curl https://indahl.ai/api/v1/time_servers?server=nist
curl https://indahl.ai/api/v1/find_study?query=readout&division=qia
curl https://indahl.ai/api/v1

The OpenAPI description is at /api/openapi.json. Responses are cached for a minute.
