Changelog

Every release of indahl.ai

Every release of indahl.ai is one commit to the site’s source, made by the release step after every check passes. This page lists those commits, newest first, with each message as written. A new desk, a new channel and a change to a method each show up here on the day they go live. Each release appears here once the next release is built. The list starts on 10 November 2026.

Releases whose message names a person or an internal working file are left out of this list. Every release is stamped and listed with its files on the release stamps page, and every fix to a published reading is on the corrections log.
