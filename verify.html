Verify

Check that what you received came from us

We sign what we publish with one Ed25519 key. A valid signature shows that a feed, an API answer, an alert receipt or a webhook came from us and was not changed on the way.

What is signed

  • Every feed: feed.xml, feed.json, the corrections feed, each desk's changes feed, each organisation feed, the newsletter feed and the changelog feed.
  • Every JSON answer of the API under /api/.
  • Every alert receipt as JSON, transparency.json, build.json and each deletion receipt.
  • Every webhook delivery, beside the shared-secret signature it already carries.

A signed answer carries the header x-indahl-signature-ed25519 (the signature of the exact body bytes, base64url) and x-indahl-key-id. The same signature is also served on its own at the same address with .sig added, for example /feed.xml.sig. A feed can change between two requests, so the header of the same answer is the exact pair.

Check a feed in Python

Needs the cryptography package (PyPI).

import base64, urllib.request
from cryptography.hazmat.primitives.serialization import load_pem_public_key

def get(url):
    return urllib.request.urlopen(urllib.request.Request(url, headers={"User-Agent": "verify"}))

key = load_pem_public_key(get("https://indahl.ai/.well-known/indahl-signing-key").read())
r = get("https://indahl.ai/feed.xml")
body = r.read()
sig = r.headers["x-indahl-signature-ed25519"]
key.verify(base64.urlsafe_b64decode(sig + "=" * (-len(sig) % 4)), body)
print("signature ok")

Check a feed in Node

Node 18 or later, no packages.

const crypto = require("crypto")

async function main() {
  const pem = await (await fetch("https://indahl.ai/.well-known/indahl-signing-key")).text()
  const r = await fetch("https://indahl.ai/feed.xml")
  const body = Buffer.from(await r.arrayBuffer())
  const sig = Buffer.from(r.headers.get("x-indahl-signature-ed25519"), "base64url")
  console.log(crypto.verify(null, body, crypto.createPublicKey(pem), sig) ? "signature ok" : "SIGNATURE FAILED")
}
main()

Check a webhook delivery

For a webhook the signed message is the timestamp header, a full stop and the raw body, the same message the shared-secret signature covers.

# in your receiver, with the raw request body and headers
msg = headers["x-indahl-timestamp"].encode() + b"." + raw_body
sig = headers["x-indahl-signature-ed25519"]
key.verify(base64.urlsafe_b64decode(sig + "=" * (-len(sig) % 4)), msg)
// in your receiver, with the raw request body as a Buffer
const msg = Buffer.concat([Buffer.from(req.headers["x-indahl-timestamp"] + "."), rawBody])
const ok = crypto.verify(null, msg, crypto.createPublicKey(pem), Buffer.from(req.headers["x-indahl-signature-ed25519"], "base64url"))

If we ever replace this key, the new key is published here and in the JSON Web Key Set beside the old one, and the change is listed in the corrections log.
