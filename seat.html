SEAT · An Outside Seat Reads Our Pages

Division: ATLAS

Is the site we serve the site we published?

Our release script checks the live site from the same machine that built it, which is one seat. This page reports a second seat. A GitHub runner on a network that is not ours fetches each page of this site and the same file from the public repository, compares them byte for byte, reads the age of every live feed against a limit set from its schedule, and recomputes the hash chain of our records. We only relay what the runner saved to a public repository, and every probe is kept there.

The plan was committed before the first probe. A page counts as drifting only when it differs in two probes in a row, because a release writes the site before the repository. The rolling reading covers the last 24 probes. One runner is one seat and does not speak for every network. The probe, its plan and every saved probe are in the nodes repository.

Named here and want to answer a row? Respond

An incident is a run of consecutive probes that each had a drifting page, a feed past its limit or a broken chain, however many probes it lasts. Consistent: none of the last 24 probes had an incident. Above: three or more incidents. Anything in between, fewer than 24 probes, or a newest probe more than three hours old reads cannot tell. The table of incidents names each one, with its first and last probe and what the probes saw. The probes are triggered by our scheduler, not by a timer.
