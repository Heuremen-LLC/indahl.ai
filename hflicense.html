HFLICENSE · Stated License Against the License File

Division: IRIS

Does the license a repository states match the license file it carries?

A Hugging Face model or dataset states its license in its card. Its repository may also carry a license file. For the most downloaded models and datasets this page compares the two. Repositories with no stated license, no license file in the root, or a license that is custom or named for one model are not comparable and are counted apart. The most common reason a repository cannot be compared is that it has no license file at all.

The plan, with its four dated addenda, was committed before the first repository was read. Every reading error found along the way is logged there, with the read run again each time. A row where the tag and the file point to different licenses is opened by hand and the reason written beside it. The page does not say which side is right.
