Division: IRIS

Does the install command a project gives work today?

The description of a PyPI project usually tells the reader to run pip install and its name. For the most downloaded projects this page takes the first such command, keeps it only if it names the project, and asks pip whether it could install it today on a fresh Python 3.12. The check is a dry run on wheels only, so no project's code is run. Projects with no command, a command with other options, a path or URL, a placeholder, or no wheel that fits are not comparable and are counted apart.

The plan was committed before the first project was read, and its dated addenda and notes are listed with it. The first two addenda came from full reads before anything was shown: a placeholder the reader did not recognise, and commands that install something other than the project. Both changed the reading and the whole read was run again each time.

The plan states a limit of this check. A command that names a project by its own PyPI name has little room to fail, so the check can barely show a failure. The upper bound on the failing share also treats projects as independent, although families of projects share one install line.

The outcome is read under Standards 2.0 from 12 November 2026, with the rule in the plan addendum dated that day. The share of disagreements is read against zero. It reads ABOVE when its whole 95 percent interval is at or above 0.05, CONSISTENT when the whole interval is below 0.05, and otherwise CANNOT_TELL with a reason. An interval that holds both 0 and 0.10 reads CANNOT_TELL (TOO_WIDE_TO_RESOLVE). Fewer than 30 comparable rows also read CANNOT_TELL (TOO_WIDE_TO_RESOLVE). Beside each share the page prints the count of failed reads and the share of CANNOT_TELL split by reason.

Named here and want to answer a row? Respond

Agree: pip would install the command. Disagree: pip fails because a target is not on PyPI, the requirements conflict, or no version matches although the project has a wheel that fits. Above: the lower end of the 95 percent interval of the failing share is above 0.10. Consistent: the upper end is below 0.05. Otherwise, and with fewer than 30 comparable projects, cannot tell.
