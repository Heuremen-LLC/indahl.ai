Rerun MODEL with Python 3. No packages needed.
1. Make a folder with a subfolder named raw.
2. Save these MLCommons files into raw as inf_5.0.json, inf_5.1.json, inf_6.0.json and inf_6.1.json:
   https://raw.githubusercontent.com/mlcommons/inference_results_v5.0/main/summary_results.json
   https://raw.githubusercontent.com/mlcommons/inference_results_v5.1/main/summary_results.json
   https://raw.githubusercontent.com/mlcommons/inference_results_v6.0/main/summary_results.json
   https://raw.githubusercontent.com/mlcommons/inference_results_v6.1/main/summary.json (save it as inf_6.1.json)
   The SHA-256 of each file we used is in claims.json.
3. Put check_nvidia_v51.py, check_amd_v51.py, check_amd_v60.py, check_intel.py, check_lambda.py, check_nebius.py, check_supermicro.py, check_dell.py, check_dell_posts.py, check_hpe.py, check_supplement.py, check_nv_v61.py, check_amd_crusoe_v61.py, check_v51_posts.py, check_lambda_v61.py, check_lenovo_v51.py, check_nebius_v61.py, check_redhat_v50.py, check_redhat_v60.py, check_coreweave_v61.py, check_intel_v61.py, check_azure_v61.py, check_cisco_x210c_v51.py, check_cisco_c845a_v61.py, check_hpe_v51.py, check_supermicro_v50.py, check_azure_training_v60.py, check_amd_repro_v60.py, check_cisco_blog_v61.py, check_amd_techdive_v61.py, check_amd_repro_v61.py, check_amd_repro_v51.py, check_amd_repro_v50.py, check_amd_pruning_v51.py, check_nv_v60.py, check_nv_v50.py, check_nv_training_v50.py, check_nv_training_v51.py, check_nv_training_v51b.py, check_broadcom_v51.py, check_google_v50.py, check_kveritas.py, build_storage_v30.py, check_storage_nebius_v30.py, check_storage_azure_v30.py, check_training_posts.py and build_accelerators.py next to raw and run each with python3 -I. The AMD v6.0 check also reads raw/inf_5.0.json and raw/inf_5.1.json.
3b. The NVIDIA training rows read the result logs in github.com/mlcommons/training_results_v6.0 (git clone --depth 1). Put the clone at raw/training_v60, run parse_training.py, then check_nv_training.py. The AMD training rows also read the round 5.0 and 5.1 clones (training_results_v5.0 and training_results_v5.1, saved as raw/training_v50 and raw/training_v51): run parse_training_round.py on each, for example python3 -I parse_training_round.py raw/training_v51 training_v51_times.json, then check_amd_training.py. parse_training.py applies the olympic average and scaling factors the way MLCommons' own result summarizer does.
4. The Apple rows were measured on one MacBook Pro. mac_run.jsonl is the raw reading. To repeat it on a Mac, compile stream.c with clang -O3 stream.c -o stream, compile gpu_bw.swift with swiftc -O gpu_bw.swift -o gpu_bw, close every other app, and run the commands in run_idle.sh. check_apple_mac.py reads the run file and the Mac's own reports.
The vendor sentences are quoted from the pages named in claims.json, fetched on 2026-10-28.
