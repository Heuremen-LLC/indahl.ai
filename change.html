CHANGE · Announced Shutdown Dates, Kept Over Time

When a vendor says something ends on a date, does the date hold?

Model and API providers publish tables of what they are retiring and when. This page reads those tables from Anthropic, OpenAI, Google and Cloudflare on a schedule and keeps every reading. It lists what ends in the next 60 days, how much notice the tables that state a deprecation date gave, and every date that moved, was added or disappeared since the first reading. Open weight models carry no vendor shutdown date and are not in this version.

The plan was committed before the first reading, with one dated addendum for a parsing error found before anything was shown. The test counts only dates that pass after we started watching, so it starts empty and fills as dates pass. Every move is opened on the vendor's page by hand. A moved date is not called a fault. A later date can be a kindness and an earlier one a security response.

Named here and want to answer a row? Respond

Held: a stated date passed and never changed while we watched. Moved: it changed at least once before it passed. Removed early: the row left the page before its date. Fewer than 30 dates in the test reads cannot tell. Notice is the days from a stated deprecation date to the shutdown date. Lifespan is the days from release to shutdown and is not notice. Sources are the vendors' own deprecation pages, linked in the code folder.

Plan, code and trend history for this page are public: change. Every plan was committed before the data it describes.
