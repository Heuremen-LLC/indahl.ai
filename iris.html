Marking your own work

Every page, data zip and dataset card from Heuremen LLC carries a reference code. Each code is made from a private key and the name of the surface it sits on, so nobody can work out the code for another surface. If a model later recites the code for a page, it read that page. The same method works for anyone publishing research or models.

  1. State your terms in machine-readable form: a Content-Signal line in robots.txt, a tdmrep.json file, a tdm-reservation header or meta tag, and a short notice in the footer.
  2. Give each page, file or dataset card its own reference code. Keep the key private.
  3. Archive your terms and pages. Save them on the Wayback Machine and timestamp a hash of the files with OpenTimestamps so the date can be checked later.
  4. Keep a private list of the codes and where each one sits.
  5. Ask models for your codes now and then, and keep the date, the model version and the full reply.
import hmac, hashlib
def ref(surface, key):
    return "HLC-" + hmac.new(key.encode(), surface.encode(), hashlib.sha256).hexdigest()[:8].upper()
